Built a Personal Expense Analyzer using Python, Pandas, Numpy and Matplotlib (for plots)

-> How to run:
   1. Clone the repo 
   2. download the dependencies using pip install -r requirements.txt
   3. Delete the contents of data.csv (remove everything, keep the headers though)
   4. Enter python main.py 
   5. Enjoy your CLI Personal Expense Analyzer

-> Features:
   1. Add an expense with the following info: amount, date, category (Choose from the options provided), and additional notes
   2. View your previous Expenses (Last n, this month, this year, etc)
   3. Analyze (graphical and non-graphical) your expenses: you can get summary for this month, compare month by month, see expense distribution, etc via beautiful visual representations like scatter, bar and pie plots.

Built by me, as a learner project after I learnt these libraries.
